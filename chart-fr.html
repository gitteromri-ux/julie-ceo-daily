Terms explained
  • Meta Ads Manager = Meta's (Facebook/Instagram) ad platform. Campaign → ad sets (audience + budget) → ads.
  • Spend = money Meta charged. Budget = daily (or lifetime) budget set live on the campaign or ad set.
  • Impressions = times ads were shown. Reach = unique people. Frequency = impressions ÷ reach.
  • CPM = cost per 1,000 impressions. Clicks (all) = any click incl. likes/profile. CTR (all) = clicks ÷ impressions.
  • Link clicks = clicks to the website. Link CTR = link clicks ÷ impressions. CPL = cost per lead.
  • Landing page views (LPV) = link clicks where the page loaded and the pixel fired.
  • Leads = Meta "lead" result (sign-up forms and pixel leads). These campaigns are Lead Gen, so leads are the main result.
  • Checkouts started / Purchases = pixel InitiateCheckout / Purchase events. ROAS = purchase value ÷ spend; shown only if purchases exist.
